# Planning Document - Iteration 2 Preserved Snapshot

This file preserves the planning intent that was documented during Iteration 2. It has been rewritten for clarity, but the substance remains intentionally historical. It should be read together with `Planning_document_ITR3.md`, which explains how the project evolved by the final release.

## Original Big Stories Carried Into ITR2

1. Build a term schedule.
   This remained the primary product goal, although the implementation scope was reduced relative to the earliest ambition.

2. Plan a full degree timeline.
   This remained a long-term goal, but it was not fully implemented in Iteration 2.

3. Save and compare plans.
   The comparison part was dropped, while the ability to save planning work was still considered in progress.

4. Eligibility and rule feedback.
   The original idea evolved from explicit course recommendations toward a checklist-based view of program requirements.

## Detailed User Stories Recorded In The ITR2 Plan

1. Create a new term.
   This changed from free-form term creation to choosing from an available term list.

2. Browse and search courses.
   This was recorded as implemented and working for the user base.

3. Add a course to the term plan.
   This was recorded as working as planned.

4. Add a section and show the weekly timetable.
   This was recorded as implemented.

5. Detect and warn about conflicts.
   The plan notes that the behavior was being revised to explain which courses conflict and what the user must choose between.

6. Save and load a term plan.
   This remained in progress rather than fully closed in the ITR2 planning note.

## What This Historical Plan Tells Us

The ITR2 planning snapshot is important because it shows that:

- scheduling stayed central throughout the project
- full degree-timeline planning was still aspirational
- plan persistence was not yet complete
- rule feedback had already shifted toward a checklist model

Those themes are still visible in the final Iteration 3 release:

- schedule building is delivered
- checklist-based program feedback is delivered
- saved selections by term are delivered
- full degree-timeline planning and plan comparison remain incomplete
